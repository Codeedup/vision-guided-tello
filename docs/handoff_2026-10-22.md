### 4. Guarded real-SDK bench implemented

Commit `d121d0029da084c37dd8b0de0b3aa307297edea3` added the separate grounded
bench and its trace reviewer. The process:

- requires `--hardware`, `--propellers-removed` and `--aircraft-grounded` before
  opening a socket;
- fixes the aircraft endpoint at `192.168.10.1:8889` and requires a Windows bind
  address on the Tello subnet;
- takes a local owner lock and was run only after confirming no other Windows
  SDK client or UDP 8889 owner;
- has a literal final allowlist of `command`, `battery?`, `height?` and
  `rc 0 0 0 0`;
- rejects enabled, tracking, land, nonzero, malformed, replayed, future and stale
  decision inputs;
- emits neutral RC for stale or missing input, checks periodic battery replies,
  attempts a final neutral packet on every exit and closes the socket;
- logs command attempts and OS send results separately from uncorrelated SDK
  replies; and
- always leaves physical outcome as `UNKNOWN` because UDP evidence cannot prove
  aircraft motion or state.

The first real attempt safely stopped when the aircraft returned the undocumented
height form `0dm`. The trace was retained. Commit
`db2e2d58a709a6639ad99791a83d1946dee08bf2` added a strict height parser for
unsigned centimetres, `cm`, and the observed `dm` suffix, converts decimetres to
centimetres, and still enforces the grounded 0–20 cm bound. Ambiguous, signed,
decimal, spaced, uppercase and unknown-unit forms are rejected.
